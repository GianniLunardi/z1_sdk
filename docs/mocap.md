## QTM
- Open QTM on the Mocap PC
- Settings -> locate system
- Then make 4 different groups (software gives delays to all automatically)
- Adapt settings to environment
- Automask -> all cameras must see the spheres of the calibration pole. Then calibrate (bacchetta symbol) with the magic stick -> move it for 90 s (or another intervall can be set)
- Repeat if necessary (std should be less than 1 mm)
- Rigid body -> select all the balls (shift + click), then right click, 'Define rigid body', give it a name
- Change offset -> -530, +136.89, +27.14. Translation rigid in settings, give the opposite
